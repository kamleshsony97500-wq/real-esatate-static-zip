# UrbanNest — Static Real Estate Practice Website

A beginner/intermediate frontend practice project made with:

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Responsive design

## Run in VS Code

1. Extract the ZIP.
2. Open the `urban-nest-static` folder in VS Code.
3. Open `index.html` with Live Server.

No `npm install` is required.

## Practice tasks

Try adding:
1. Property details page.
2. Dark/light mode.
3. More filters.
4. Sort by price.
5. Login/register UI.
6. Favorites page using LocalStorage.
7. Image slider.
8. Pagination.
9. Form validation.
10. Convert the project to React later.

Note: Property images are loaded from Unsplash, so internet is needed for the remote images.
